## 📌 О проекте

Демонстрационное приложение, реализующее **TOTP (Time-based One-Time Password)** — алгоритм генерации одноразовых паролей на основе времени.

Проект создан в рамках изучения методов двухфакторной аутентификации и криптографии на C#.

## 🎯 Что такое TOTP?

**TOTP** (RFC 6238) — это алгоритм, который генерирует уникальный 6-значный пароль, меняющийся каждые 30 секунд. Используется в:

- Google Authenticator
- Microsoft Authenticator
- Банковских приложениях
- 2FA в социальных сетях

## ✨ Функциональность

| Функция | Описание |
|---------|----------|
| 🔐 Генерация OTP | 6-значный пароль на основе текущего времени |
| ⏱️ Таймер обратного отсчёта | Пароль действителен 30 секунд |
| 🛡️ Защита от подбора | Не более 3 неудачных попыток |
| 🔄 Проверка с допуском | ±1 временной интервал (устойчивость к рассинхронизации) |
| 💾 Безопасное хранение ключа | Ключ не зашит в коде, хранится в `%LocalAppData%` |

## 🔧 Технологии

- **Язык:** C# 12.0
- **Фреймворк:** .NET 8.0 (Windows Forms)
- **Криптография:** HMAC-SHA-1 (RFC 4226 / RFC 6238)

## 🚀 Как запустить

### Требования
- Windows 10/11
- .NET 8.0 SDK или Visual Studio 2022

### Инструкция

1. Клонировать репозиторий
   ```bash
   git clone https://github.com/IVEFELTTHEHATERISEUPINME/TOTP_Simple.git
2. Открыть проект:
- cd TOTP_Simple
- start TOTP_Simple.sln
3. В Visual Studio нажать F5 для сборки и запуска

## 📖 Как пользоваться

1. Введите ID пользователя — любое имя (поле не может быть пустым)
2. Нажмите «Сгенерировать TOTP» — появится окно с паролем
3. Введите пароль в поле и нажмите «Подтвердить вход»
4. Успешный вход — программа покажет сообщение об успехе

## 🧪 Тестовые сценарии

| Сценарий | Ожидаемый результат |
|---------|----------|
| Правильный пароль | ✅ Доступ разрешён |
| Неверный пароль (1-2 раза) | ⚠️ Осталось попыток: X |
| Неверный пароль (3 раза) | 🔒 Блокировка доступа |
| Истечение 30 секунд | ⏰ Таймаут, генерация нового |
| Ввод букв/символов | 🚫 Блокируется на уровне ввода |
| Пустой ID | ❌ Предупреждение о вводе |

## 🔐 Безопасность

### Что защищено

- Секретный ключ не зашит в коде — хранится в %LocalAppData%\TOTP_Simple\secret.key
- Пароль действителен 30 секунд — перехваченный пароль бесполезен
- Лимит попыток (3) — защита от brute-force
- Валидация ввода — только цифры

### Важное замечание

В демонстрационных целях пароль показывается в всплывающем окне. В реальных системах OTP должен доставляться через защищённый канал (SMS, push, аутентификатор).
